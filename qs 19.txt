Q19. BFS Maze: Shortest Path

Language: Python

Code:
from collections import deque

maze = [
    [0, 0, 1, 0],
    [1, 0, 1, 0],
    [0, 0, 0, 0],
    [0, 1, 1, 0]
]

start = (0, 0)
goal = (3, 3)

q = deque()
q.append((start, [start]))
visited = set()
visited.add(start)
found = False

while q:
    current, path = q.popleft()
    x, y = current

    if current == goal:
        print("Shortest Path:", path)
        print("Path Length:", len(path) - 1)
        found = True
        break

    # Up, Down, Left, Right
    moves = [(-1, 0), (1, 0), (0, -1), (0, 1)]
    for dx, dy in moves:
        nx = x + dx
        ny = y + dy

        if (0 <= nx < len(maze) and
            0 <= ny < len(maze[0]) and
            maze[nx][ny] == 0 and
            (nx, ny) not in visited):
            visited.add((nx, ny))
            q.append(((nx, ny), path + [(nx, ny)]))

if not found:
    print("No Path Exists")

Sample Input:
Maze and start/goal are defined in the program.
Start = (0, 0), Goal = (3, 3)

Sample Output:
Shortest Path: [(0, 0), (0, 1), (1, 1), (2, 1), (2, 2), (2, 3), (3, 3)]
Path Length: 6

Grid values: 0 = free cell, 1 = obstacle. Start = (0, 0), Goal = (3, 3).
