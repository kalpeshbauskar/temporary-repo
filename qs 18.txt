18.	A text string text of length n. A pattern string pattern of length m. Find all starting indices i in the text such that the substring text[i:i+m] is exactly equal to the pattern using the Naive String Matching Algorithm approach. Constraints: 0 ≤ m ≤ n

Language: Python

Code:
text = input("Enter text: ")
pattern = input("Enter pattern: ")

n = len(text)
m = len(pattern)
found = False

for i in range(n - m + 1):
    j = 0
    while j < m and text[i + j] == pattern[j]:
        j += 1
    if j == m:
        print("Pattern found at index:", i)
        found = True

if not found:
    print("Pattern not found")

Sample Input:
AABAACAADAABAABA
AABA

Sample Output:
Pattern found at index: 0
Pattern found at index: 9
Pattern found at index: 12
